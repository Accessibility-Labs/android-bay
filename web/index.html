    A LITTLE GUIDANCE GOES A LONG WAY

    Let’s get connected.

    Everything runs over USB. Your phone can stay offline.

    Set up the USB connection

    1. Unlock your phone.

      Enter its screen PIN, pattern or password. Charge the phone and connect it directly to your PC with a USB data cable.

    2. Reveal Developer options.

      On the phone, tap Settings → About phone → Build number seven times. On Samsung, try Settings → About phone → Software information → Build number. Enter the screen lock if asked.

    3. Turn on USB debugging.

      Go back to Settings → System → Developer options → USB debugging. Older phones may show Developer options directly in Settings. Accept the phone’s warning.

    4. Allow this PC.

      Unlock the phone and approve Allow USB debugging? Only approve a PC you trust. If a USB mode is requested, choose File transfer / MTP.

    5. Refresh and select your phone.

      Back in Transfer center, click Refresh. Select a phone marked Ready, check the detected storage, and choose where to save.

    Menu names vary by Android version and manufacturer. You can turn USB debugging off when finished.

    Not showing up?

    Waiting for authorization
    Unlock the phone and approve the USB debugging prompt. If it never appears, unplug and reconnect; then try Developer options → Revoke USB debugging authorizations and reconnect.
    Device is offline
    Reconnect the cable, keep the phone unlocked and click Refresh. Try a different PC USB port or data cable.
    No devices detected
    Confirm USB debugging is on. A charge-only cable will not work. Some phones need the manufacturer’s Windows USB driver installed on the PC first.
    Connection tools are missing
    Use the complete Android Bay Windows package. A source-only copy needs the official Android SDK Platform Tools configured on the PC before it can connect.

    Export phone records

    In Transfer center, choose Install phone helper. This adds the bundled helper app to the selected phone through USB.

    1. Click Open helper on phone.
    2. Tap Grant permissions and allow only the categories you want to export.
    3. Tap Create export in the helper and wait for it to finish.
    4. Return to the PC. Keep Phone data exports checked and start the transfer.

    Denied permissions and unsupported categories are recorded. Installing the helper alone does not export anything.

    Optional legacy Android backup

    In Transfer center → Advanced options, select Attempt legacy Android backup and start the transfer. When the phone shows its backup confirmation screen, review it and approve the backup yourself. Apps may exclude data, and some Android versions do not support this feature.

    If the phone shows Fresh password, that field sets the password for this backup archive. Enter it directly on the phone and keep it safely in your own local records; you may need it to read the archive later. Do not put it in chat.

    If the backup times out: close the old backup confirmation screen on the phone first. Once the PC transfer has stopped, click Resume transfer on the PC and review the newly opened phone confirmation screen before approving again.

    Google Maps Timeline and app locations

    The location check reads saved map/route exports and photo/video GPS without sending locations anywhere. If the phone offers it, Google documents Settings → Location → Location services → Timeline → Export Timeline data → Continue. Save to Downloads, then resume or start a transfer to acquire the new export before running the archive checks.

    Timeline off does not mean old history is gone. Leave that setting unchanged and export any retained data if the option is available. Check each account separately where the phone offers an account selector.

    Older offline builds may not have this menu, and availability without an account is not guaranteed. Do not clear Maps or Google Play services data; that can remove stored history. Other navigation, fitness or travel apps may offer their own GPX/KML/JSON export.
